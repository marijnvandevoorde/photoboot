How to use the calibration

  1. Print the width calibration. The solid bar reveals where the print head stops; the numbers below show the exact dot column of each tick.
  2. Note the highest number that is fully inside the sticker. That is your safe max width. Also note where the solid bar stops — that is the physical head width.
  3. Optionally run the fine calibration (16-dot steps) to pinpoint the sticker edge within ~1.3 mm.
  4. Set Target width to that number (nearest multiple of 8), then try the text / pattern / image buttons.
